# Controle de Medições

Aplicação para registrar serviços de obra, seus valores contratados e o percentual executado. O sistema calcula automaticamente o valor medido e os totais.

## Funcionalidades

- Cadastro e exclusão de medições
- Cálculo automático do valor executado
- Resumo dos valores contratados e medidos
- Persistência de dados com `localStorage`
- Layout responsivo

## Tecnologias

HTML5, CSS3 e JavaScript puro.

## Como executar

Abra o arquivo `index.html` no navegador.
