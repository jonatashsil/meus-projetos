# Gerador de Senhas

Aplicação para criar senhas aleatórias e personalizadas diretamente no navegador.

## Funcionalidades

- Tamanho configurável entre 6 e 40 caracteres
- Opções de maiúsculas, minúsculas, números e símbolos
- Indicador visual de força
- Botão para copiar a senha
- Geração com a API criptográfica do navegador

## Tecnologias

HTML5, CSS3, JavaScript e Web Crypto API.

## Como executar

Abra o arquivo `index.html` no navegador.
