# Calculadora de Orçamento de Obra

Aplicação web para estimar o custo inicial de uma obra a partir da área, do valor de materiais, da mão de obra por metro quadrado e de uma reserva para imprevistos.

## Tecnologias

- HTML5
- CSS3 responsivo
- JavaScript
- `Intl.NumberFormat` para valores em reais

## Como executar

Abra o arquivo `index.html` no navegador. O projeto não precisa de instalação ou servidor.

> O resultado é apenas uma estimativa e não substitui um orçamento executivo detalhado.
