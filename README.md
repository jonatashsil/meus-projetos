# Meus Projetos

Repositório pessoal de Jonatas Henriques para organizar projetos de programação e registrar minha evolução na transição profissional para a área de tecnologia.

## Projetos principais

- [`ponto-eletronico/`](./ponto-eletronico/) — MVP de ponto eletrônico com autenticação, PostgreSQL, Prisma e geolocalização.
- [`autonexo/`](./autonexo/) — classificados de automóveis com busca, filtros, favoritos e publicação de anúncios.

## Projetos básicos

- [`orcamento-obra/`](./orcamento-obra/) — calculadora de materiais, mão de obra e reserva para imprevistos.
- [`controle-medicoes/`](./controle-medicoes/) — cadastro de serviços, percentuais executados e valores medidos.
- [`controle-gastos/`](./controle-gastos/) — organização de receitas, despesas e saldo financeiro.
- [`lista-tarefas/`](./lista-tarefas/) — lista de tarefas com filtros e armazenamento no navegador.
- [`gerador-senhas/`](./gerador-senhas/) — geração de senhas personalizadas com indicador de força.

Os projetos básicos foram desenvolvidos com HTML, CSS e JavaScript, possuem layout responsivo e podem ser executados diretamente no navegador.
