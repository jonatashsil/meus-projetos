# AutoNexo

Plataforma de classificados direcionada à compra e venda de automóveis, motos e utilitários.

🔗 **Versão online:** https://classificados-online.jonatas-henriques.chatgpt.site

## Funcionalidades atuais

- Busca de veículos por marca e localização
- Filtros de carroceria, ano e faixa de preço
- Ordenação por relevância, ano e preço
- Cards de anúncios com fotos e informações principais
- Favoritos
- Janela com os detalhes do veículo
- Formulário para iniciar a publicação de um anúncio
- Área comercial para lojas e revendedores
- Layout responsivo para computador e celular

## Tecnologias

- React
- TypeScript
- Vinext
- Vite
- Tailwind CSS

## Executar no computador

É necessário ter o Node.js 22 ou mais recente instalado.

```bash
npm install
npm run dev
```

Depois, abra no navegador o endereço informado pelo terminal.

## Situação do projeto

Esta é a primeira versão navegável do AutoNexo. Os veículos exibidos são demonstrativos. As próximas etapas são cadastro de usuários, banco de dados, armazenamento permanente das fotos, painel administrativo e contratação de destaques.
